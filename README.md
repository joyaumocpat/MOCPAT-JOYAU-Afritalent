# AfriTalent 
Plateforme Freelance Tech en Afrique
Auteur : Neige MOCPAT
Promotion : L1 RT— ISI 

## Description

AfriTalent est une plateforme fictive de mise en relation entre freelances tech 
et entreprises africaines. Ce projet a été réalisé dans le cadre du cours de 
développement web du Semestre 2. Il présente les fonctionnalités, les tarifs 
et les profils de freelances de la plateforme.


## Technologies utilisées

- HTML5 sémantique
- CSS3 (Flexbox, Grid, Bento Grid, animations, variables CSS)
- Bootstrap 5
- JavaScript Vanilla (ES6+)
- Google Fonts (Syne + Inter)
- Bootstrap Icons
- Git & GitHub Pages


## Fonctionnalités principales

- Dark Mode / Light Mode avec localStorage
- Compteurs animés au scroll (IntersectionObserver)
- Filtrage dynamique des freelances par catégorie
- Validation complète du formulaire de contact
- Navbar dynamique au scroll
-  Bouton retour en haut
-  Animations fade-in au scroll
-  Design responsive (mobile, tablette, desktop)
-  Bento Grid sur la page d'accueil et à propos


## Pages du site

| Page | Description |
|------|-------------|
| index.html | Page d'accueil avec hero, catégories, témoignages |
| freelances.html | Catalogue de freelances avec filtrage |
| tarifs.html | Plans tarifaires et FAQ accordion |
| about.html | Histoire, équipe, valeurs et chiffres clés |
| contact.html | Formulaire de contact avec validation JS |
